# Changelog

All notable changes to this project are documented here. Format based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- `.editorconfig` and Dependabot config for automated dependency updates
- Comprehensive SEO metadata (Open Graph, Twitter Cards, keywords)
- PWA manifest for installable progressive web app support
- RFC 9116-compliant `security.txt` for responsible disclosure
- Light mode with one-line nav
- Initial Porta marketing site (iOS 26 liquid glass, black & white)

### Changed
- Constrained site to the middle two-thirds of the viewport
- Tightened hero layout and column spacing
- Enlarged and vertically centered nav
- Refined glass reflections and alignment

### Fixed
- Nav wrapping by flexing the Glass inner wrapper
